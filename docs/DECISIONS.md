- 이미지: Wikimedia Commons, 작가·라이선스 표기.
- 추가 요구(패키지 비교, packageTours 스키마, compare.ts, 수집 원칙, 하네스 반영)를 PLAN에 반영.
- 월/필터 상태는 URL 쿼리로 동기화(제안).
- 점수의 가격 항목: 기본은 지역 평균 대비, 전체 평균 병용 옵션 제공(제안).
- 2026-10-28 package.json 직접 구성(create-next-app은 비어있지 않은 폴더라 사용 안 함). eslint는 flat config 직접 실행.
- 2026-10-28 점수 가격 항목: 같은 지역 비교 가능 도시 3개 미만이면 전체 평균 사용(샘플 단계에서 지역 평균이 무의미).
- 패키지 박수 불일치는 1박 환산하지 않고 통계에서 제외 + 제외 개수 표시(환산은 근거 약함).
- 기후: Open-Meteo ERA5 2019–2023 5년, 일 최저/최고의 월평균, 연도별 월 강수합의 평균.
- 패키지 스키마에 extraKnownKRW(금액 확인된 불포함 합계), termsClear, departureDate 추가.
- 2026-10-28 GitHub 비공개 저장소 BLACKHEADHUB/travel-value. main + phase별 브랜치/PR.
- 가격 보강: 출처 있는 연중 대표 왕복가(flightPriceTypical) 필드 추가, 월별 값 없을 때만 사용하고 UI에 "(연중 대표가)" 표시. 재수집은 sonnet.
- 이미지: imageFile(파일명)만 수집하고 라이선스 확인·URL은 fetch-images 스크립트가 채움.
- 딥링크: 항공 Google Flights(q 파라미터), 숙소 Booking.com. 날짜는 선택 월의 다음 15일 출발.
- 필터/정렬/월은 URL 쿼리로 유지(공유 가능). 상세는 ?m 으로 월 전달.
- 추천 일정은 비행시간 구간 규칙(≤4h 2~3박, ≤7h 3~4박, ≤10h 5박+, 그 외 7박+).
- 패키지 출발일이 기준일보다 과거면 경고(지난 가격).
- 2026-10-28 경비는 출처 통화 원값(dailyCost.local)으로 저장, `npm run fx`(open.er-api.com)가 KRW 환산. 수집기의 환율 가정 금지(가정 환율이 실제와 최대 10% 차이 확인).
- 이미지는 fetch-images가 Commons API로 라이선스(CC0/CC BY/BY-SA/PD) 확인 후 채움, 429는 지수 대기 재시도.
- reviewer 반영: 패키지 제목은 판매처 문구 대신 "도시 N박 N+1일 패키지"로 중립화, 지난 출발 상품(방콕)·다국가 투어(파리) 제거.
- 패키지 비교 기본 박수 = 그 도시 패키지에서 가장 흔한 박수, 없으면 비행 5h 이하 3박/초과 4박 (pickNights).
- 비자를 무비자/전자여행허가/비자 3단계(kind)로, 점수 100/70/0. 한시 무비자는 validUntil, 여행일이 넘으면 "확인 필요".
- 테마 점수에서 랜드마크 개수 제외(입력 편차).
- 월별 항공값이 한쪽(min 또는 max)만 있으면 단일값으로 사용.
- 김포(GMP) 출발 옵션 제거: GMP 데이터 0건이라 오해 소지. 스키마 필드는 유지.
- 예산 필터: 경비 정보 없는 도시는 숨기되 개수 표시 + "정보 없는 곳도 보기" 토글.
- 조건 불명확 패키지 가격은 작게 "(포함 조건 미확인 — 가격만 참고)"로 표시.
- 2026-10-28 seasonLevel = 항공·숙박 수요(가격) 기준. 근거는 seasonSource(주로 Kayak 노선 '가장 비싼/싼 달'). 근거 없는 달은 null.
- 비자 출처 우선순위: 외교부 0404 → 해당국 정부/대사관. 상업 대행사·블로그 금지. 베트남 무비자 validUntil 2028-03-14, 중국 2026-12-31.
- 비행시간은 Kayak 노선 평균(왕복 평균 포함 가능), 출처 flightHoursSource.
- 타이베이 경비(3,400 TWD) 삭제: 출처가 범위만 제공 — 범위에서 값을 고르지 않는 규칙 적용.
